# Overview

Aplicación móvil desarrollada en **Flutter** para niños con autismo no verbal (2-5 años) que les permita comunicarse mediante imágenes. Los niños podrán seleccionar imágenes de diferentes categorías (comida, lugares, emociones) para expresar sus necesidades. La interfaz será simple, con botones grandes y colores claros, adaptada para niños pequeños.
